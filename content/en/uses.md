The tools behind the projects — inspired by
[uses.tech](https://uses.tech). Last updated: November 2026.

## Hardware

- **ThinkPad T14 Gen 4** — main development machine (Fedora)
- **Custom desktop** — homelab worker: k3s cluster node, GitLab runners, CI builds
- **Raspberry Pi 4** — always-on lightweight services
- **Keychron mechanical keyboard** + vertical mouse
- **Bose QuietComfort** headphones — deep-work essential

## Software

- **Fedora Linux** — daily driver, both laptop and servers
- **Neovim** + tmux — most editing happens here
- **VS Code** — when a GUI debugger or preview pays off
- **Firefox** — main browser, hardened profile
- **Git** on self-hosted GitLab — mirrors to GitHub for public work
- **Cloudflare** — DNS, Workers, D1, KV, R2, Tunnels; the whole portfolio runs on the free tier
- **Oracle APEX** — enterprise RAD, professional toolkit
- **Hugo** + Astro — static sites (like this one)

## Homelab

- **k3s Kubernetes** with Argo CD GitOps — every service declared in Git
- **Self-hosted GitLab** — family repositories, CI runners, container registry
- **Cloudflare Tunnels** — zero open ports, Access policies on top
- **ntfy** — self-hosted notifications (homelab + project alerts)

## Services

- **Cloudflare Pages** — static hosting for all armands.* sites
- **Zoho Mail** — behind the contact forms (via Cloudflare Worker)
- **Netlify** — legacy builds (blog mirror)
- **GitLab CI** + GitHub Actions — build pipelines everywhere
